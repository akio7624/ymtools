# APK / IDX 파일
Artdink 사의 게임에서 주로 발견되는 `*.apk`, `*.idx` 파일의 구조를 분석하여 정리한 폴더이다.

## 파일 개요
* apk: 게임 리소스 파일들을 담고 있는 아카이브 파일이다. 파일 앞부분에 파일 목록 등의 메타데이터 테이블이 있고, 그 뒤에 실제 파일 데이터가 이어진다.
* idx: 같은 게임의 apk 파일 여러 개가 가진 메타데이터 테이블을 하나로 합친 색인 파일이다. 실제 파일 데이터는 들어 있지 않다.

게임은 내부적으로 idx 파일만 읽은 다음, idx 파일에 기록된 위치를 이용해 각 apk 파일의 데이터를 직접 읽는다.  
따라서 apk 파일을 수정했다면 idx 파일도 반드시 다시 만들어야 한다.
